# Security policy

## Supported versions

Security fixes go into the latest release of lazydocker-ng. Please check that
you can reproduce an issue on the latest release before reporting it.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[open a private security advisory](https://github.com/peauc/lazydocker-ng/security/advisories/new).

Do not open a public issue for a vulnerability.

Include what you can of:

- the lazydocker-ng version (`lazydocker-ng --version`) and your OS;
- how to reproduce the problem, and what an attacker could do with it;
- any fix or mitigation you have in mind.

This is a volunteer project. Reports are answered as soon as possible, and
you will be credited in the advisory unless you prefer not to be.
